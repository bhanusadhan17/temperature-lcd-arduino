# temperature-lcd-arduino
Temperature sensor with LCD display using Arduino Uno

## Components Used
- Arduino Uno
- TMP/LM35 Temperature Sensor
- LCD 16x2 Display
- 10k ohm Potentiometer
- 220 ohm resistor
- Breadboard
- Jumper wires

## Pin Connections
- TMP middle pin → A0
- LCD RS → Pin 8
- LCD EN → Pin 7
- LCD D4-D7 → Pins 6,5,4,3

## How It Works
TMP sensor reads temperature, converts to Celsius
and displays live reading on LCD every second.

## Tools Used
- Arduino IDE
- Tinkercad (simulation)
